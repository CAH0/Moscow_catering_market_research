# Исследование рынка общественного питания Москвы

## 📋 О проекте

Инвесторы из фонда **«Shut Up and Take My Money»** решили открыть заведение 
общественного питания в Москве, но ещё не определились с форматом (кафе, 
ресторан или бар), локацией, меню и ценами. В рамках проекта проведён 
исследовательский анализ рынка Москвы, результаты которого помогут 
инвесторам выбрать подходящее место и концепцию.

Данные основаны на информации сервисов **Яндекс Карты** и **Яндекс Бизнес** 
за лето 2022 года.

> ⚠️ Информация из Яндекс Бизнес могла быть добавлена пользователями или 
> найдена в общедоступных источниках и носит исключительно справочный характер.

## 🎯 Цели исследования

- Изучить структуру рынка общественного питания Москвы
- Проанализировать категории заведений, их распределение по округам
- Исследовать соотношение сетевых и несетевых заведений
- Изучить посадочные места, рейтинги и их корреляции с другими признаками
- Проанализировать вариацию среднего чека в зависимости от района
- Сформулировать рекомендации для открытия нового заведения

## 📊 Данные

**`/datasets/rest_info.csv`** — информация о заведениях:
- `name` — название заведения
- `address` — адрес
- `district` — административный район (например, «Центральный административный округ»)
- `category` — категория («кафе», «пиццерия», «кофейня» и т.д.)
- `hours` — дни и часы работы
- `rating` — рейтинг в Яндекс Картах (до 5.0)
- `chain` — сетевой статус (0 — не сетевой, 1 — сетевой)
- `seats` — количество посадочных мест

**`/datasets/rest_price.csv`** — информация о среднем чеке:
- `price` — категория цен («средние», «ниже среднего», «выше среднего»)
- `avg_bill` — средняя стоимость заказа в виде диапазона/строки
- `middle_avg_bill` — числовая оценка среднего чека (медиана диапазона)
- `middle_coffee_cup` — числовая оценка цены чашки капучино

## 🔍 Этапы работы

### Шаг 1. Загрузка данных и знакомство
- Загрузка двух датасетов, изучение структуры, объёма, типов данных
- Оценка соответствия данных описанию, выявление пропусков
- Объединение датасетов в единый датафрейм

### Шаг 2. Предобработка данных
- Проверка и преобразование типов данных
- Анализ и обработка пропущенных значений
- Поиск явных и неявных дубликатов (с нормализацией текстовых полей)
- Создание нового столбца `is_24_7` — работает ли заведение ежедневно и круглосуточно

### Шаг 3. Исследовательский анализ данных (EDA)
1. Категории заведений — количество объектов по каждой категории
2. Административные районы — распределение заведений по округам и по категориям в ЦАО
3. Сетевые vs несетевые заведения — в целом и в разрезе категорий
4. Посадочные места — аномалии, выбросы, типичные значения по категориям
5. Рейтинги — распределение средних рейтингов по категориям
6. Корреляция рейтинга с категорией, районом, сетевым статусом, местами, ценой, `is_24_7` + проверка сильнейшей связи
7. Топ-15 популярных сетей Москвы — количество заведений, средний рейтинг, категории
8. Вариация среднего чека (`middle_avg_bill`) по районам — влияние удалённости от центра

### Шаг 4. Итоговый вывод и рекомендации
- Общий обзор проделанной работы
- Главные выводы по исследовательским вопросам
- Рекомендации для заказчика на основе анализа данных
